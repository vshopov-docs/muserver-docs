Configure monsters

Monster configurations are in the text files in the directories ServerFolder/Data/Monster and ServerFolder/Data/MonsterSetBase.

Monster.txt

Monster.txt contains the base monster statistics and the monster IDs. Other configuration files reference the monster IDs.

Table 1. Monster.txt properties
Property Description
Index The monster's internal ID. Other configuration files reference this ID when they want to spawn the monster. Must be unique.
Rate Legacy property. Spawn rate - used when multiple scripts try to spawn monsters. Not relevant currently because spawn logic is handled elsewhere. Leave at 1.
Name The monster's display name. Used in the client and logs.
Level The monster's level. This affects experience yield, drop tables and relative combat difficulty.
MaxLife Maximum hit points. The amount of damage a monster has to take before it dies.
MaxMana Maximum mana points. Used by spellcasting monsters, 0 for non-spellcasters.
DamageMin The minimum damage the monster inflicts on attack.
DamageMax The maximum damage the monster inflicts on attack.
Defense Physical defense value used to calculate damage reduction
MagicDefense Magical defense value used to calculate damage reduction.
AttackRate Used in hit chance calculations against player defense.
DefenseRate Used in hit chance calculations against player attack.
MoveRange Maximum movement range from the spawn point in tiles. Prevents monsters wandering too far.
AttackType Defines how the monster engages in combat. 0 = Melee, 1 = Ranged, 2 = Spellcaster.
AttackRange Maximum range at which a monster can attack.
ViewRange The range at which the monster notices players.
MoveSpeed Determines how fast the monster moves.
AttackSpeed Delay between attacks. A lower value = faster attacks.
RegenTime Monster respawn delay in seconds.
Attribute Elemental attribute. 0 = Earth, 1 = Fire, 2 = Water, 3 = Wind, 4 = Dark.
ItemRate Modifier for the overall item drop chance.
MoneyRate Modifier for the amount of dropped Zen.
MaxItemLevel The maximum level item the monster can drop.
MonsterSkill Skill ID that the monster uses.
Resistance1-4 Amount of resistance for different elements. 1 is ice, 2 is poison, 3 is lightning and fire, 4 is earth and wind. The value is a modification applied on the final damage, where 0 is full damage is 255 is no damage.

Example:

Index Rate Name Level MaxLife MaxMana DamageMin Damage Max Defense MagicDefense AttackRate DefenseRate MoveRange AttackType AttackRange ViewRange MoveSpeed AttackSpeed RegenTime Attribute ItemRate MoneyRate MaxItemLevel MonsterSkill Resistance1 Resistance2 Resistance3 Resistance4
0 1 "Bull Fighter" 6 100 0 16 20 6 0 28 6 3 0 1 5 400 1600 10 2 130 20 6 0 0 0 0

MonsterSetBase

The MonsterSetBase folder contains one .txt file for each zone in the game. Each .txt file contains spawn points for both friendly NPCs and hostile monsters. You can specify spawn points either as exact coordinates or as a rectangular areas where monsters spawn at random positions.

Table 2. NPC spawn properties
Property Description
Monster Monster ID. Those are listed in Monster.txt
MapNumber Zone ID. Those are listed in MapManager.txt
Range Defines randomization within the spawn position when used with a fixed spawn point, and distance between spawns in area spawn points.
PositionX Exact X coordinates for the spawn point.
PositionY Exact Y coordinates for the spawn point.
Direction Defines which direction the NPC faces when spawned. -1 value = random direction.
Comment Helpful reminder for debugging and configuration.

Example:

Monster MapNumber Range PositionX PositionY Direction Comment
230 00 00 062 130 03 //Wandering Merchant Alex
Table 3. Monster spawn properties
Property Description
Monster Monster ID. Those are listed in Monster.txt
MapNumber Zone Id. Those are listed in MapManager.txt
Range Defines randomization within the spawn position when used with a fixed spawn and distance between spawns when used in area spawn points.
BeginPosX The starting X position of a rectangular area spawn point.
BeginPosY The starting Y position of a rectangular area spawn point.
EndPostX The ending X position of a rectangular area spawn point.
EndPostY The ending Y position of a rectangular area spawn point.
Direction Defines which direction the monster faces when spawned. -1 value = random direction.
Quantity Defines how many monsters are spawned in the spawn point.
Comment Helpful reminder for debugging and configuration.
