Start your Mu Server

The server pack provides a start-up tool in ServerFolder/StartUp. The tool is preconfigured to the relative paths of each of the components and is set to start each server component in sequence with a 1000ms pause between them.

Always start the Mu Server components in the following order to ensure that each one initializes its connections correctly. The correct order is:

  1. Connect Server
  2. Join Server
  3. Data Server
  4. Game Server

To start your server with the StartUp tool:

  1. Launch ServerFolder/StartUp/StartUp.exe
  2. Click the green arrow button.

The tool starts the server components automatically. When the console of each component prints "Active Mode", your server is live.
