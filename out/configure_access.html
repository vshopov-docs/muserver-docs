Configure database access

The Data Server, Join Server, and Connect Server use System Data Source Names (DSNs) to access the MuOnline database. The server pack provides registry files to create the necessary System DSNs. To add the registry files:

  1. Browse to ServerFolder/DB/. There are two registry files there - MuOnline.reg and MuOnline64.reg.
  2. Right click each file and click Merge.

This creates the system DSNs that the server components use to access the databases. You can check if they are there and if they work through the Windows ODBC Data Administrator.
