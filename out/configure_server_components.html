Configure the server components

The Mu Server components communicate with each other over the network, using connection details from their individual configuration files. They interact as follows:
  • The Connect Server and the Join Server must know each other's IP addresses and ports. They also use the ODBC System DSN to validate client account information in the database.
  • The Connect Server must also know the Game Server's IP address.
  • The Data Server requires the ODBC System DSN to connect to the database.

To verify each component's configuration file:

  1. Navigate to the .ini file of each component in ServerFolder/component.
  2. Edit the configuration file with a text editor. Verify that each component has the correct IPs, ports and System DSN.
