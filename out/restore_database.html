Restore the Mu Server database

To restore the server database, you must have administrative access to an SQL instance. This guide assumes SQL Server is already installed and accessible on your system.

You can restore the server database using the Microsoft SQL Server Management Studio or an SQL query.

To restore with the SQL Server Management Studio:

  1. Log into your SQL instance through SQL Server Management Studio.
  2. Right click Databases in the Object Explorer window and select Restore Database....
  3. Select the Device radio button and click the ellipsis (...) button. This opens the Select backup device window.
  4. In the Select backup device window, click Add, browse to the location of MuOnline.bak on your system, and confirm your selection.
  5. Select Files in the Select a page panel.
  6. Mark the Relocate all files to folder check box and verify that the file paths to your .mdf and .ldf files are correct.
  7. Click OK.

When the restore completes, the MuOnline database appears under Databases in your Object Explorer window.

Alternatively, use the following SQL query for scripting or automation purposes:

RESTORE DATABASE MuOnline
FROM DISK = 'C:\path\to\MuOnline.bak'
WITH MOVE 'MuOnline' TO 'C:\Program Files\Microsoft SQL Server\MSSQL\Data\MuOnline.mdf',
MOVE 'MuOnline_log' TO 'C:\Program Files\Microsoft SQL Server\MSSQL\Data\MuOnline_log.ldf'
